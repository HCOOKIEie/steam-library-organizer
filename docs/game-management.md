# 游戏管理

桌面版左侧的「游戏管理」读取当前账号的 Steam 游戏，以及已经导入 Steam 的非 Steam 游戏。

## 操作

- 文件夹旁的「＋」新建分类文件夹。支持重命名和删除；删除后游戏回到「未分类」，不删除游戏文件。
- 拖动游戏左侧的点阵调整顺序；拖到左侧文件夹移动游戏。移动后的游戏放在目标文件夹末尾，同批游戏保持原顺序。
- 勾选多个游戏可批量移动、加标签、去标签、移到末尾。全选仅选择当前筛选结果，切换文件夹或搜索会清空选择。
- 「手动排序」保存拖动顺序；「按名称」「按时长」仅改变当前显示，不覆盖手动顺序。也可以用每行的上下箭头排序。
- 「移到末尾」可在任意排序视图操作，完成后自动切回手动顺序；同批游戏保持原来的手动顺序。
- 点击右侧时长填写个人记录；清除后恢复显示 Steam 原始时长。支持非 Steam 游戏。自定义记录标有「自定义」，只保存在本软件，不修改 Steam 官方时长，也不会自动计时。
- 修改自动保存。「撤销修改」撤销最近一次操作，再点一次恢复该操作。重启软件后仍可撤销。
- 导入独立安装游戏及二游仍用「导入本机游戏」。导入成功后重新打开游戏管理，或点刷新。

## 同步到 Steam

「同步到 Steam…」先显示分类列表。确认后要求 Steam 完全退出，备份后写入。

文件夹成为同名 Steam 分类，标签成为「标签 · 名称」分类。本功能只替换自己上次同步的分类，保留 Steam 原有手动分类及自动分类工具生成的分类。空文件夹也会同步。预览为空时会明确提示清除本功能之前同步的分类。

**手动顺序和自定义时长只在本软件生效，不会同步到 Steam。** 删除游戏管理里的文件夹或标签后，需要再次同步才会更新对应的 Steam 分类。

Steam 分类备份与原工具共用，可从主界面的「恢复最近备份」恢复。

## 数据与冲突处理

本地管理数据位于应用数据目录 `SteamLibraryOrganizer/library-workspaces/` 下，按 Steam 安装路径和账号分别存储。每份 JSON 包含文件夹、游戏归属、标签、排序、个人时长；`.undo.json` 保存上一次修改。使用原子替换及跨进程锁，磁盘写入失败时保留原数据。

每次修改校验账号与版本，多窗口修改冲突时要求刷新。暂时不在扫描结果里的游戏保留原来的管理数据，以便之后恢复。同步预览绑定账号、本地版本、Steam 分类文件和源数据指纹，30 分钟后过期；Steam 数据变化时拒绝写入。

当前仅支持单层分类文件夹；每个游戏属于一个文件夹，可以有多个标签。不会移动硬盘上的游戏安装目录。
