# 本机游戏导入

此功能自 v1.2.0 提供，包含在 EXE 和便携包中。

## 使用

1. 在 WebView2 主界面左侧打开“导入本机游戏”，点击“扫描本机”。
2. 需要时添加游戏文件夹，也可关闭“自动发现”仅扫描指定位置。
3. 检查名称、路径与启动信息，勾选入口。已识别游戏默认勾选；引擎特征和未知程序仅作为待确认候选。
4. 点击“导入所选”，可修改 Steam 分类，默认为“本机游戏”。完全退出 Steam 后确认导入。
5. 重新启动 Steam，在游戏库查看新增条目。

导入后默认自动匹配并补齐游戏图片；已有条目也可从“游戏封面”批量补图。详见 [游戏封面](game-artwork.md)。

同一游戏的快捷方式、启动器与本体合并为一行；有多个入口时，可在“启动信息”的“启动方式”中切换，导入所选的一个入口。
已知游戏结合程序名与启动器游戏参数识别，Unreal 结合安装目录归并，普通程序按实际路径识别。
不会仅凭显示名称合并不同游戏；共用启动器的不同游戏参数继续保留为不同游戏。
写入时再次去重，即使请求同时选了同一游戏的多个入口，也只添加一次。
已存在的条目不会改名、改参数或覆盖自定义封面。没有可靠识别的游戏可扫描其具体文件夹，
在“启动信息”中更正名称。文件夹不可直接选择磁盘根目录。

## 扫描范围

- Windows 安装记录、桌面与开始菜单 `.lnk`。读取快捷方式目标、参数和工作目录，不执行目标。
- 已连接的本地固定磁盘、移动磁盘：优先扫描 Game、Games、游戏、单机、二游、XDGAME、GOG Games、Epic Games、BiliGame、miHoYo Launcher、HoYoPlay、Hypergryph Launcher、WeGameApps、Tencent Games、XboxGames 等目录。
- 浅查盘根下其他安装文件夹及 Program Files 下的发布商文件夹；发现游戏特征后继续向下扫描。安装记录同样参与查找。
- Epic 已安装游戏清单；Windows 已注册且包含 MicrosoftGame.config 的 Xbox / GDK 游戏，通过系统应用入口导入，保留原有授权和启动流程。
- 原神、星穹铁道、绝区零、崩坏3等已知程序名；游戏快捷方式可保留终末地、绝区零等启动器的游戏参数。
- Unity、Unreal、Godot、Ren’Py、RPG Maker 等目录特征只作为候选证据；这些引擎也可用于普通软件，仍需确认。
- 过滤安装、卸载、更新、反作弊安装器、崩溃报告、网页进程等辅助程序；排除 Steam 库目录。
- 单次扫描上限为 60 秒、500,000 个文件系统条目、1,000 个候选入口；具体游戏目录最多 9 层，其他目录浅查 3 层。
  游戏位置优先，各位置轮流按层扫描；单个目录的大量资源文件不会挤掉其他目录的扫描机会。
  每个游戏位置最多检查 10,000 个子目录或 EXE，其他位置为 1,200 个。界面列出扫描位置，并标出未扫完的位置。
  快捷方式解析单独有 12 秒超时，Windows 注册游戏查询有 15 秒超时。
  支持停止扫描；取消不产生可导入计划。不会跟随遍历中遇到的符号链接或目录联接。

扫描不能保证识别任意自定义路径、游戏平台协议、模拟器及所有 UWP 游戏。未找到的游戏可添加具体安装文件夹继续扫描。
仅有空目录、未下载本体或程序无法读取且没有 Windows 注册游戏入口时，不会生成一个无法验证的启动项。
优先检查平时使用的游戏快捷方式。此版本不会绕过启动器、登录、更新或反作弊要求。

## 写入与恢复

实际修改的是 `Steam/userdata/<当前账号>/config/shortcuts.vdf`，使用二进制 KeyValues。
新增条目追加到现有根对象，旧条目的原始字节（包括未知字段）保留；不支持的类型或损坏文件会拒绝写入。
UI 只能提交本次服务端扫描计划中的候选 ID 和显示名称，不能通过导入请求替换可执行文件路径。
计划有效期 30 分钟，绑定账号、原文件摘要和可执行文件大小/修改时间。状态变化必须重新扫描。

写入持有现有的 Steam 跨进程锁，检查 Steam 进程，保存完整原文件快照，再通过临时文件原子替换。
备份在账号配置目录 `nonsteam-organizer-backups/` 中，JSON 记录原始字节、摘要和文件原先是否存在。
撤销必须匹配导入后的文件摘要，先保存 `.pre-undo.vdf`，再恢复原数据；原先没有文件则恢复为不存在。
备份不随收藏夹备份轮换删除。退出软件后仍可撤销；Steam 启动或游戏游玩可能改变快捷方式元数据，
此时为了保护后续改动会拒绝整体恢复。可在 Steam 中手动移除对应非 Steam 条目。

导入仅添加启动快捷方式，不赋予 Steam 游戏授权、成就或云存档。后台监控新游戏、
全平台协议适配和 tkinter 入口不在当前版本范围。

## 验证

`python -m unittest tests.test_nonsteam -v` 验证原始字节保留、中文路径、启动参数、重复/过期/伪造计划、
运行中的 Steam、外部修改、备份损坏、写入失败、扫描取消和撤销。
`npm test` 验证候选选择、名称转义、确认步骤、错误保留和取消行为。预览服务的本机游戏数据为虚构示例，写入被拒绝。
