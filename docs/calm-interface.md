# 简约：黑白与荧光绿工作台

参考用户指定的 OKX（欧易），查看其官方 [The New OKX Interface: Faster, Clearer, Unified](https://www.okx.com/en-us/learn/okx-interface-update) 界面截图：借鉴黑白层次、清楚的数字主次、紧凑分区和少量荧光绿操作强调。没有复制 OKX 的标志、代码、图片、字体或金融内容。

## 实现

- `steam_ui/calm.css` 仅覆盖 `data-appearance="calm"`，兼容已有亮色/深色偏好。深色主按钮为荧光绿，亮色为墨色；警告和失败继续使用语义颜色。
- 首屏使用原创 CSS 卡片几何图案。图案标明“分类演示”，扫描统计仍全部来自原有数据；不添加虚构图表、收益或游戏状态。
- 点击卡片先散开，再错峰归位；鼠标视差采用收敛后停止的阻尼跟随。入口为原生按钮，支持 Enter / Space；减少动效时保留静态构图并禁用重播。
- 背景方格随鼠标局部亮起、偏移，点击空白处或“唤醒背景”扩散方形波纹。最多保留三道波纹，交互结束后停止绘制；进入审阅、隐藏窗口与减少动效时暂停。Canvas 分辨率限制为 300 万像素，不可用时回退为静态点阵。
- 生成预览时以实际元素的位置差做 300ms 位移，界面可立即搜索、勾选。动画不覆盖操作控件。所有生成结果（包括空预览）均收起首页画面，保留恢复提示。
- 原有规则、计划时效、写入确认、Steam 退出检查及备份流程保持原有逻辑。新增的 `organizer-preview-will-render` 仅用于读取过渡前的布局。
- 切换主题、隐藏窗口、减少动效和进入审阅都会清理装饰动画。没有持续自动循环、网络资产或新运行时依赖。
- 低窗口高度下整理范围改为三列紧凑卡片；窄屏沿用上下排列与底部操作栏。高对比度模式使用系统描边并隐藏装饰构图。

## 本地查看

```powershell
python scripts/preview_ui.py --port 8763
python scripts/preview_ui.py --export dist/previews/Calm-preview.html --appearance calm
```

切换至顶栏“简约”。示例只读取合成数据，拒绝实际写入。保存的外观偏好优先于离线文件的默认主题。

## 验证范围

前端回归涵盖卡片及背景闲置停帧、隐藏/减少动效取消、Canvas 回退、操作控件不触发背景波纹、过渡期间仍可选择分类、规则计数、空预览与离线资源内嵌；浏览器检查亮暗外观、搜索、过滤勾选、确认窗口及响应式布局。主题与互动背景已纳入 v1.1.1 Windows 发布包。
