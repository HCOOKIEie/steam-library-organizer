# 简约：以整理操作为中心

本轮根据用户反馈，收起展示型画面，减少重复说明，让范围、规则和预览成为界面主体。设计参考 `apple-design` 与 `emil-design-eng` 中的即时反馈、可中断运动和克制层次原则，使用本地系统字体；没有引入新的图片、字体或运行依赖。

**状态：v1.1.2。** 新简约已纳入 EXE 和便携包；此前旧版发布已撤回。

## 本轮调整

| Before | After | Why |
| --- | --- | --- |
| 荧光绿强调、首页卡片演示、方格背景 | 浅色白灰、深色灰黑、蓝色操作强调 | 减少装饰，突出当前操作与选中状态 |
| 大标题、重复提示、规则副标题和统计备注 | 简短标题与主要数字，详细资料仍可展开 | 降低阅读密度，保留需要时可查的信息 |
| 卡片散开归位、视差与背景波纹 | 预设和语言选中滑块、按钮按压、预览过渡 | 动效解释选择与布局变化 |

旧卡片、背景 Canvas 与“唤醒背景”控件已移除。其余外观的陈列粒子、P3R / P5R 人物和主题动效继续保留。

## 布局与反馈

- 简约外观保留双栏：左侧范围与分类方式，右侧统计和预览。隐藏重复的流程栏与设置标题；空预览直接说明下一步。
- 浅色使用白灰表面与蓝色强调，深色使用灰黑表面与浅蓝选中态；主操作按钮保持蓝底白字。警告、成功和错误保留各自语义颜色。
- 预设与语言选择使用临界阻尼弹簧滑块。再次点击会从当前位置与速度转向新目标；停稳后不再调度帧。自定义规则组合不高亮无关预设。
- 按钮按下时轻微缩至 97%；菜单短暂淡入。生成预览时，以实际布局差进行 240ms 位移，分类内容使用 220ms 淡入；搜索和勾选不等待过渡完成。
- 键盘、触控、减少动态效果或系统高对比度状态下，滑块立即就位。键盘操作、切换外观、隐藏窗口和减少动效会取消运行中的预览过渡；返回时不续播旧动画。
- 窄屏按上下顺序排列设置与预览，底部操作栏固定；短窗口压缩间距，规则与预览区域仍可滚动。高对比度模式隐藏滑块，以系统选中描边显示状态。

视觉改动由 `steam_ui/calm.css` 与 `steam_ui/calm.js` 实现。共享界面的重复文案也作了精简；扫描、分类、计划时效、写入确认、Steam 退出检查与备份逻辑保持原有流程。
