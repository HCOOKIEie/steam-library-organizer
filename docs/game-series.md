# 系列分类

左侧「分类方式」勾选「游戏系列」，点击「生成预览」，审阅后选择要写入的分类。可以与首字母、游戏类型等规则组合，沿用备份、账号检查和 Steam 退出检查。

识别来源：

- Steam 的本地 `appinfo.vdf` 中 `common.associations` 的 `franchise` 条目。读取时保留多个系列；与开发商或发行商同名的条目，以及已知的 EA Play、WB Games 等订阅与厂商品牌，不作为系列，避免把厂商旗下游戏全部合并。
- 内置常见系列的中英文名称规则，包括女神异闻录、生化危机、最终幻想、黑暗之魂、如龙等。用中文显示名和缓存中的英文名匹配；两种语言的游戏归入同一中文系列。已知名称规则优先，避免宽泛的品牌系列覆盖具体系列。

规则只匹配明确的系列名称，不根据相同的首词、发行商或数字自动猜测未知系列。未能识别的进入「未识别系列」，资料缺失与非游戏内容分别处理。标题规则不能保证覆盖所有作品，结果以预览为准；漏掉的可以用「游戏管理」手动建文件夹或加标签。

自动规则的范围是主界面当前选择的 Steam 条目范围。它不创建或移动「游戏管理」中的本地文件夹，也不改动游戏安装位置。手动文件夹、标签和已导入的非 Steam 游戏在「游戏管理」中单独整理。

全程离线，不调用 AI，也不用 API Key。内置别名维护在 `steam_series.py`，添加新系列时需同时补充中英文与误匹配测试。缓存结构版本已更新，旧版元数据缓存会重新解析，Steam 原始文件不改动。

Steam 官方的系列资料设置说明：[Franchise Pages](https://partner.steamgames.com/doc/store/franchise_pages)。
