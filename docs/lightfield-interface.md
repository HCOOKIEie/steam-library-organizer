# 光域：可切换的空间背景

2026-10-25 的源码改版替换上一版孤立的折叠线束。用户要求参考本机 Code-Codex 多种背景的细节、纵深和互动强度，同时保有自己的构图与图形语言。检查过本机 appearance 插件的机制；本项目未复制其源码片段、着色器、字符图集或图片。

## 三种场景

- **棱阵**：有独立侧面与厚度的三角切面地形；细密点刻纹理、矿物色反射与局部抬升。区别于参考的 ASCII 矩形砖块，没有字符贴图或 RGB 故障边缘。
- **游流**：12,000 个菱形微粒组成三股有前后纵深的空间流。远近尺寸、透明度与少量铜色变化表达空间，不表示真实游戏数量。
- **回响**：连续的二维采样网格在三维空间形成驻波曲面，点击与指针影响局部高度。它与离散切面、点云使用不同拓扑。

画面铺满窗口。规则栏、顶栏和操作栏使用不透明度约九成的深色表面；正文区域在 GPU 中局部压暗。预览面板是实体表面，进入审阅后背景停帧并降至 16% 不透明度。浅色有对应的冷白表面和较深的材质颜色。

## 操作与状态

背景选项是原生按钮，具备名称和 pressed 状态；选择记录在 `steam-organizer-space-scene`，未知值回退棱阵。切场用可取消的 240ms 淡入；暂停、减少动效、隐藏、进入审阅或切换外观会取消淡入。重构图只改变装饰种子，不改变分类规则、计划或勾选。

指针经过空白区域会产生局部抬升和小幅相机跟随；点击、空格或回车发出最长 2.4s 的高度波，最多三道同时存在。按钮、输入、标签、链接、summary、select 和对话框不触发背景脉冲。触屏不使用悬停响应。

手动暂停保留既有 `steam-organizer-particles-paused` 偏好；暂停时仍可切换静态场景和重构图。系统或应用减少动效优先，禁用暂停按钮并给出状态；高对比度模式隐藏背景并停止帧调度。窗口隐藏、其他主题、审阅和 pagehide 均停止渲染；pagehide 还释放 GPU 资源和输入监听。

## 渲染与回退

`steam_ui/vault.js` 内置独立编写的 WebGL2 顶点/片元程序，使用透视相机、切面网格、点云和线网。无需运行时下载、图形库或新依赖。GPU 空闲可见时以约 32ms 的绘制间隔呈现缓慢运动；交互后的短窗口以约 15ms 间隔调度。这是调度目标，不是所有设备的帧率保证。

DPR 上限 1.5，绘制缓冲区上限 200 万像素。Canvas2D 回退使用投影几何，交互结束后停帧；无法使用 Canvas 时保留生成的 SVG 静态场景。回退保持空间与操作能力，但没有 GPU 的完整材质或粒子密度。渲染上下文丢失会立即停止并显示静态场景，恢复后重建资源。
