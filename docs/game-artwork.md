# 游戏封面

此功能自 v1.2.0 提供。匹配和下载都是普通代码完成，不调用语言模型、图像模型或识图服务。

## 使用

新导入时默认勾选“导入后自动补齐游戏图片”，导入完成后按游戏名和已知别名搜索现有资源。
只有唯一的完整名称匹配才自动写入；无条目、只有相似名称、多个同名结果分别说明原因。Steam 图库没有条目且未配置 SteamGridDB 时，提示配置图库密钥后重试。补图失败不撤回已经成功导入的游戏。

已有的非 Steam 游戏可从左侧“游戏封面”打开，选择“自动补齐缺图”，或搜索游戏名称、选择结果、预览图片后写入。
支持竖版封面、详情背景、徽标、横版封面。默认保留已有图片；需主动勾选“替换已有图片”才能替换。
搜索、下载预览不修改 Steam。写入和撤销要求 Steam 完全退出；完成后重新启动 Steam 查看。

名称匹配不等于图片授权或游戏授权。匹配只关联图库条目，不更改游戏的启动路径、参数和原有名称。

## 图片来源

- 本地图片：自动补图先检查游戏安装目录里的 PNG/JPG。仅尺寸适合、文件名明确且同类候选唯一时自动采用。共享启动器不自动跨游戏选图。程序图标不当作封面，不解包或执行游戏文件。
- 搜索栏切换「本地图片」，留空路径检查游戏目录；也可填写或选择启动器的图片文件夹。点击结果预览，每类最多列出 6 张候选，可切换后确认写入。图片文件在搜索后发生变化时需重新搜索。本地来源不联网、不用图库密钥或 AI。

本地扫描最多 5 秒、15,000 个目录项、64 MB 图片数据和 5 层子目录；跳过日志、引擎、二进制、打包资源和链接目录。达到上限时提示选择更具体的目录。没有散装图片的游戏仍需其他来源，不把图标放大生成封面。

- Steam：使用公开商店名称搜索和当前资源信息，图片从 Steam CDN 下载；无须 API 密钥。
- [SteamCMD.net](https://www.steamcmd.net/)：公开、无须认证的第三方 appinfo 元数据镜像，补充带哈希的中文封面、徽标等资源地址；图片本身仍来自 Steam。不是 Valve 官方服务。
- [SteamGridDB](https://www.steamgriddb.com/api/v2)：可选图库，需用户自己的 API 密钥。密钥仅用于当前打开的封面窗口，关闭即清空，不写入设置文件、日志或备份。

联网搜索会向对应服务发送游戏名称，查询资源时发送该图库的游戏编号，不发送本机游戏路径或 Steam 账号信息。
网络请求校验 HTTPS 与域名，保留证书验证，不绕过访问限制；无网、无结果或来源缺图时显示错误或缺图状态。
Steam 图片节点连接失败时尝试另一个官方 CDN 节点。验证后的图片缓存于软件数据目录 `artwork-cache/`，7 天内复用，缓存上限 128 MB；缓存不可写时继续使用下载结果。
不保证所有游戏、全部四种图片都能找到，也不把模糊搜索的第一项直接当作正确游戏。

## Steam 文件与保护

读取当前账号 `config/shortcuts.vdf` 中的短 AppID，将图片写入同级 `grid/`：

| 类型 | 文件名 |
| --- | --- |
| 竖版封面 | `<appid>p.png` 或 `.jpg` |
| 详情背景 | `<appid>_hero.png` 或 `.jpg` |
| 徽标 | `<appid>_logo.png` 或 `.jpg` |
| 横版封面 | `<appid>.png` 或 `.jpg` |
| 徽标位置 | `<appid>.json`，仅在缺少时创建默认位置 |

短 AppID 来自已有快捷方式，和查询图片时用的商店游戏编号不同，不会将二者混写。
徽标位置格式参考 [SteamGridDB 对现有 Steam 客户端的兼容处理](https://github.com/SteamGridDB/steam-rom-manager/pull/903)。用户已调整的位置保留。

图片只接受静态 PNG/JPEG，单张最多 8 MB，验证文件头、完整性标记和尺寸，拒绝 SVG/HTML、异常尺寸和非图库域名。
每次预览绑定 Steam 账号、快捷方式摘要、游戏编号、当前图片摘要和 30 分钟有效期。
写入持有已有跨进程库锁，检查 Steam 退出状态。原图备份写入 `config/artwork-organizer-backups/`，随后逐文件原子替换；中途失败回滚已经写入的文件。
撤销只恢复最后一次补图，并检查写入后的摘要。用户之后又换过图时拒绝覆盖；撤销自身也保存安全快照。

## 验证

`python -m unittest tests.test_artwork -v` 覆盖四种文件名、徽标位置、原图保留、替换与精确撤销、部分写入失败回滚、Steam 运行中、账号/快捷方式/图片变化、伪造计划、非精确匹配、URL 与文件类型约束、桌面接口和 HTTP CSRF。

`npm test` 覆盖选择游戏、名称转义、四种预览、默认保留已有图片、新导入后的自动补图范围、失败后保留预览，以及离线页面资源内嵌。

终末地的实际只读验证：名称对应 Steam 条目 4732690，下载到中文竖版封面、3840×1240 背景、中文徽标和横版封面。测试下载仅保存在开发缓存，未用作对用户 Steam 文件的写入测试。
