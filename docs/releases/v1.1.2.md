# v1.1.2 · 光域空间与简约工作台

- 光域提供三个可切换的原创互动空间：棱阵、游流、回响。新增立体切面、细密刻纹、空间粒子流与驻波网格，支持鼠标局部抬升、点击 / 键盘波动、场景记忆和暂停。
- 进入审阅、窗口隐藏、减少动效或渲染上下文丢失时停帧；提供 Canvas2D / SVG 静态回退与恢复。
- 简约改为白灰 / 灰黑表面和蓝色操作强调，精简重复说明；加入可中途改向的选项滑块、按压反馈和预览过渡。
- 保留 P3R / P5R 主题，以及分类、搜索、勾选、备份、Steam 退出检查、写入和恢复流程。
- 项目源码采用 MIT 许可证，保留第三方组件各自的许可文件。
- 旧版 v1.1.0 / v1.1.1 已撤回，相关旧外观提交已从公开分支和标签历史移除，请使用此版本。

## 下载

推荐 **SteamLibraryOrganizer-1.1.2-win-x64-portable.zip**，完整解压后运行其中的 `SteamLibraryOrganizer.exe`，许可文件已经内置。

单文件版为 **SteamLibraryOrganizer-1.1.2-win-x64.exe**；选择单文件版时，请同时下载并保留 **SteamLibraryOrganizer-1.1.2-third-party-licenses.zip**。

`SHA256SUMS.txt` 提供校验，`BUILD-DEPENDENCIES.txt` 和 `BUILD-VERIFICATION.json` 记录依赖与资源核验结果。

## 验证与环境

61 项 Python 测试、36 项前端测试通过；核对两种包的内嵌资源、运行库、x64 版本和 ZIP 完整性。浏览器检查了三种空间、亮暗、小窗口、暂停、减少动效、搜索和勾选；尚未完成干净 Windows 10/11 设备的完整兼容矩阵。

面向 Windows 10/11 x64；新界面需要 WebView2 Runtime，缺失时回退 tkinter 界面。程序未代码签名，首次启动可能出现 SmartScreen 提醒，请核对下载来源与 SHA-256。
