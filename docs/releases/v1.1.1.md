# v1.1.1 · 简约主题与互动背景

- 重做简约主题：黑白层次、荧光绿操作强调，卡片归位、鼠标视差及分类预览过渡。
- 新增互动方格背景：鼠标经过时点亮、偏移；点击空白处或“唤醒背景”释放方形波纹，支持键盘操作。
- 动效闲置停帧，隐藏窗口、进入审阅和减少动效时暂停；支持亮暗外观与 Canvas 不可用时的静态回退。
- 整理源码目录：文档集中在 `docs/`，构建工具在 `scripts/`，删除停用的旧版入口；EXE 与便携包统一通过 Release 下载。
- 保留陈列室、P3R、P5R 主题及原有分类、备份、写入和恢复流程。

## 下载

推荐 **SteamLibraryOrganizer-1.1.1-win-x64-portable.zip**，完整解压后运行其中的 EXE。
也可下载单文件 **SteamLibraryOrganizer-1.1.1-win-x64.exe**，同时保留同版本的第三方许可 ZIP。
校验文件为 `SHA256SUMS.txt`，构建依赖与资源校验结果随 Release 附上。

## 验证与环境

61 项 Python 测试、31 项前端测试通过；核对两种包的内嵌界面、运行库、x64 版本资源和 ZIP 完整性。
用户已确认本次界面构建在本机测试正常；这不代表已完成全部干净 Windows 10/11 设备兼容矩阵。
