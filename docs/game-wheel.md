# 游戏轮盘

原「光域」入口改为「轮盘」，保存过的外观设置继续使用。显示真实库内游戏，已安装优先，同状态按 Steam 游玩时长排列；这不会更改游戏管理里的手动顺序。

- 拖动、滚轮、左右箭头或方向键切换；Home / End 到首尾。
- 搜索或勾选「仅已安装」筛选。「随机选择」只选择游戏，不会启动游戏或操作 Steam。
- 「管理这个游戏」打开游戏管理并按当前名称筛选。
- 生成分类预览后自动进入审阅，回到轮盘不会清空已选分类和搜索。

封面从 Steam 官方 CDN 按需加载；旧地址失效时，读取当前元数据中的图片地址。请求只使用公开 AppID，不发送账号和本机路径。没有对应图或离线时显示游戏名称缩写，不会用其他游戏的封面替代。

卡片切换后动效收束。轮盘背后的放射光束以约 30fps 缓慢流动，切换游戏时短暂增强，鼠标经过时轻微偏转；「暂停光束」可停止环境动画，并记住选择。进入预览、弹窗、隐藏窗口时停止绘制。系统或软件开启减少动效时卡片直接定位、光束静态显示；无音乐、闪屏和自动运镜。

使用 motion-web 的交互节奏和手感检查方法。HALOFLUX 只作为设计参考，图形、构图、控件和实现均为本项目重新编写。
