# P3R 菜单动效参考与本地适配

参考：[John Persona — Pause Menu - Persona 3 Reload](https://www.youtube.com/watch?v=4d6x1CIgLSc)。通过浏览器观看并放慢核对，未下载或打包游戏视频、纹理或模型。

## 实录中观察到的内容

- 约 3–4 秒的开场使用不规则蓝色与青色水体形状切入。
- 约 8–9 秒从 Skill 子菜单返回主菜单时，两个大圆形窗口从相对方向展开，窗口内露出下一层画面；圆的作用是场景遮罩，而非固定描边装饰。
- 水下背景以较大的明暗反射缓慢变化；人物有漂浮运动。

## 本次适配

- 首页、人物点击与重播使用两个错峰展开的圆形窗口，同时显示标题、水光与人物。局部裁切限定在主题画面内。
- 采用 460ms 半径变化、55ms 错峰、515ms 清理遮罩。这些是为桌面整理工具选择的时序，未声称与游戏逐帧一致。
- 224×112 Canvas 水面使用宽阔柔和的色块反射，上亮下深；人物保留既有简洁色块侧颜，加入至多 4px 浮动。
- 不复刻游戏的三维角色旋转、玻璃材质和完整菜单场景切换。角色仍是本项目的 AI 生成同人插图，来源见 `persona-art-prompts.md`。
- 暂停、减少动效、窗口隐藏、离屏、切主题及进入审阅时清除遮罩并停帧，避免留下半幅画面。P5R 与默认陈列室的视觉及交互保持原有实现。

实现：`steam_ui/persona-motion.js`、`steam_ui/persona-motion.css` 与 `steam_ui/index.html`。动画不依赖第三方运行时或网络资源。
