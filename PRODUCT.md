# Steam Library Organizer

Windows desktop tool for people with large Steam libraries. Read local metadata, choose classification rules, inspect selected collections, then back up and write only after Steam exits. Preserve manual collections and existing safeguards.

Runs offline in WebView2 with a tkinter fallback. No external services, artwork downloads, or Node runtime are needed by desktop users. The development preview uses fictional data and rejects writes and system operations.
