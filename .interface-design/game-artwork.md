# 游戏封面

An existing imported game is the unit of work. Keep game selection at left and
the four Steam artwork roles at right. A preview must identify the matched game
before enabling the write action. Exact title/alias equality is the automatic
path; ambiguous results require a user's game choice. No model or generated art.

Reuse the current theme tokens, plain labels and native dialog focus behavior.
Existing artwork is kept unless the replacement checkbox is explicitly enabled.
Source/API-key settings stay in a disclosure. Batch status reports real progress
and can stop after the current game. Import-triggered batch work targets only the
new AppIDs and opens this dialog after the import dialog closes.
